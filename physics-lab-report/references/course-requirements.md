# 课程要求与来源

来源：用户提供的《3-表面张力.pptx》，按文件中的物理幻灯片序号定位，可能与页脚页码不同。仅归纳相关要求，不分发 PPT、截图、教师联系方式或学生报告样例。

| 物理页序号 | 观察到的问题或要求 | skill 对应行为 |
| --- | --- | --- |
| 2 | 汇总七类问题：摘要、计算冗长、三线表、公式、对齐、结构分页、PDF | 报告验收总范围 |
| 3 | 摘要混入过多原始数据和中间量 | 只呈现主要结果与必要精度 |
| 4 | 摘要夹入章节索引、学习心得 | 将摘要保持为独立的实验概括 |
| 5 | 结果部分展示过多逐步算式 | 保留方法与结果，省去重复数值运算 |
| 6 | 网格表有竖线和逐行横线 | 使用三线表 |
| 7 | 无竖线但逐行分隔仍不符合要求 | 仅保留三条主横线 |
| 8 | 幂次、下标位置错误，微分分母有多余字符 | 使用数学排版并逐式检查 |
| 9 | 图大小、轴标签、范围、图注有问题 | 量与单位齐全，编号图注置于图下 |
| 10 | Lab Report / Data and Results 示例页 | 不从无文本示例推断额外规则 |
| 11 | 公式居中、编号右对齐并引用、上下标正确，正文两端对齐且行距一致 | 数学及正文版式验收 |

PPT 未在上述页面规定统一字号、页边距、摘要字数、章节数量、引文格式、不确定度统一算法或表面张力测量公式。这些应依据当前实验讲义和用户要求决定。模板中的具体版式参数是可修改的默认值。
